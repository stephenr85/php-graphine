> You are in **rushing/php-graphine** — the framework-free graph algebra behind graphine: the GraphStore contract, role sub-contracts, value types, an in-memory reference driver, and a conformance test-kit.

This is a standalone PHP Composer package with zero Illuminate/framework dependency. It defines the graph-algebra contracts and ships a reference driver against them; the Eloquent binding lives in a separate package, `rushing/laravel-graphine`.
